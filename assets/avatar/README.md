# Agent avatar

The π as a little figure: two legs and a wide brim, two eyes between them. π is also a balance beam
on two posts, which is what 知衡 says — 衡, to weigh.

- `pi-avatar.svg` / `pi-avatar.png` — deep ink background, mint letter. The default.
- `pi-avatar-light.svg` / `pi-avatar-light.png` — near-white background, deep green letter, for
  places that sit on white.

Both are 512×512 and full-bleed, so a circular crop (Feishu does this in the chat header) and a
rounded-square crop both work. The letter stays clear of the edges and stays legible at 32px, where
the eyes drop out and what is left is still a π.

To set it: 飞书开发者后台 → 应用信息 → 头像, upload the PNG (the console wants raster, not SVG).
